# Group Elements

## Introduction

This project is about implementing group presentations in Python and partial or full solutions to the word problem for different classes of groups (a Go Port in planned for later too).

## Roadmap

I might change it or do things in a different order. It depends on often unexpected considerations occuring from implementing algorithms invented by mathematicians in a computer-friendly way. If I mention a particular class of groups, I will not mark it as done until I have finished the best solution to the word problem (that I know of) of it. .

- [x] Word object to input presentations
- [] Group Presentations
- [x] Free Groups
- [] Finite Groups
- [] Abelian Groups
- [] Hyperbolic Groups
- [] Automatic Groups
- [] Polycyclic Groups
- [] Partial solution to the word problem for general group presentations
- [] Tietze transformations
- and more as I think of them lel
